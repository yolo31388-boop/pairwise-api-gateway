# 游戏内API网关与限流熔断系统

## 项目描述

游戏内API网关与限流熔断系统的bug修复项目。核心模块 `gateway/api_gateway.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 路由完全没做所有请求都发到同一个服务
- 限流完全没做玩家可无限调用API
- 熔断器完全没做后端服务挂了还在转发
- 降级完全没做服务挂了直接报错
- 认证完全没做谁都能调用API

python -m pytest tests/test_api_gateway.py -q
